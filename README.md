# Jeu MemoForme
Pattern existant :
- [ ] Chain of Responsability (CasterLink), ici s'occupe de créer la vue correspondante à une forme.
- [ ] Template (CasterLink), ...
- [ ] Prototype (MFShape), nous permet de cloner les formes.
- [ ] Look&Feel / Factory, nous permet d'avoir différents styles de bouttons et de labels
- [ ] Stratégie (Evaluation), s'occupe d'évaluer la différences entre deux conteneurs (normalisé entre 0 et 100).
- [ ] MVC, pour la gestion de l'affichage graphique selon les changements apportés au modèle.
- [ ] Observeur, avec les écouteurs "basique" et ceux sur les conteneurs de formes qui nous permettent des associations inutiles.
- [ ] Command, qui nous permet de modifier les formes et d'annuler ces modifications.
- [ ] State, s'occupe de la gestion des différents modes (Creation, Mouvement, Suppression et Redimenssionage).
